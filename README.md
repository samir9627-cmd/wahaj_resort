# 🌟 استراحة وهج | Wahaj Resort

موقع حجز استراحة عائلية فاخرة في ولاية بركاء - منطقة العقدة - سلطنة عمان.

![Wahaj Resort](images/logo.png)

---

## 🎯 عن المشروع

موقع كامل لإدارة حجوزات استراحة وهج، يتيح للعملاء:
- 🏠 تصفح الاستراحة والمرافق
- 📅 حجز التواريخ المتاحة
- 💰 حساب السعر تلقائياً
- 📸 رفع إيصال التحويل
- 📱 تأكيد الحجز عبر واتساب

---

## 🚀 المزايا

### للعميل
- ✅ تصفح الصور والمرافق
- ✅ تقويم ذكي يبين التواريخ المحجوزة
- ✅ حساب تلقائي للسعر (أيام عادية / ويكند)
- ✅ 3 أنواع حجز: بدون مبيت، مع مبيت، نصف يوم
- ✅ رفع إيصال التحويل البنكي
- ✅ إرسال تفاصيل الحجز عبر واتساب
- ✅ صفحة تأكيد الحجز مع رقم مرجعي

### للأدمن
- 🔐 لوحة تحكم محمية بكلمة سر
- 📊 إحصائيات فورية
- ✅ تأكيد / رفض الحجوزات
- 💬 تواصل مع العملاء عبر واتساب
- 🔍 فلترة وبحث
- 📥 تصدير الحجوزات إلى Excel/CSV

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|-----------|
| HTML5 | بناء الصفحات |
